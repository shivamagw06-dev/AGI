# Sprint 7 — Institutional Decision Quality (IDQ)

## Stance

**Observability only.** Measures decisions. Never reasons.

Frozen:

- Phases 1–7
- Knowledge Factory
- Historical Depth / Sector Intelligence / Macro Intelligence

## Architecture

```
Evidence Packs + Phases 1–7 outputs
        ↓
Decision Quality Engine (measure)
        ↓
Metrics → Scorecards → Hall of Fame/Shame
        ↓
Dashboards / Historical Statistics / Operational Reports
```

## Decision Object

Question, Entity, Date, Research, Portfolio, Evidence Pack, Frameworks,
Committee, Confidence, DJG, PDG, Outcome Graph, Learning Proposal.

## Replay

Question → Evidence → Research → Portfolio → Outcome → Learning  
Identical stored decision. PIT: no future leakage. Missing outcome → transparent insufficiency.

## Hall of Fame / Shame

Searchable institutional memory: exceptional / good / average / weak /
incorrect due to missing evidence / framework / macro / portfolio.

## North Star

`institutional_decision_quality`
