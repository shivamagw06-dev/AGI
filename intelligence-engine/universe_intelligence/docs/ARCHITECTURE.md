# AGIB v1.2 — Institutional Universe Intelligence

**Status:** Soft registry layer  
**Freeze:** Reasoning Architecture v1.0 · Knowledge Factory · Decision Quality

## Vision

Not “complete Indian equity.”  
**The ability to manage any institutional investment universe.**

## Architecture

```text
Universe Registry
        │
        ▼
Universe Membership Engine   (point-in-time)
        │
        ▼
Company Registry
        │
        ▼
Knowledge Factory            (FROZEN)
        │
        ▼
Evidence Factory
        │
        ▼
Existing Institutional Reasoning  (Phases 1–7 FROZEN)
```

## Non-goals

- No new reasoning engines, planners, committees, governance, or learning systems
- Frameworks never call APIs directly
- Never fabricate missing data
- Do not claim Tier-4 global coverage until quality gates pass

## Institutional Coverage

Only **Coverage Level 7 (Decision Ready)** + all quality gates PASS  
counts as Institutional Coverage.

## North-star metric

**Institutional Coverage Index (ICI)** — weighted readiness score per company.
