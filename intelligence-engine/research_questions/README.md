# Institutional Research Question Engine (IRQ) V1

**Programme:** RQ2 — Hypothesis Intelligence  
**Sprint:** 2  
**Architecture:** v1.0.1 LOCKED — soft-wire only; not a top-level intelligence layer

## Position

```
IHG (Hypothesis Generation)
        ↓
IRQ (Research Questions)   ← this package
        ↓
Evidence Collection
```

## Primary question

> What questions must be answered before this hypothesis can be accepted?

## Enhancements beyond the base brief

1. **Question Tree** — Historical → Peer → Valuation → Forecast → Thesis (logical chain of proof)
2. **Decision Impact Score** — 1–10 so analysts prioritise material questions

## Quality rules

Every question must be Specific · Answerable · Evidence-backed · Decision-relevant · Non-overlapping.

Per hypothesis minima: ≥10 questions, ≥3 contradiction, ≥2 historical, ≥2 peer, no duplicates/generics.
