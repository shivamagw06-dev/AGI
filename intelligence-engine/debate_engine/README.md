# Institutional Debate Engine (IDEB) V1

**Programme:** RQ2 — Hypothesis Intelligence  
**Sprint:** 8  
**Architecture:** v1.0.1 LOCKED — soft-wire only; not a top-level layer and not another Committee

## Position

```
Institutional Thesis Construction Engine
        ↓
IDEB (structured debate)
        ↓
Investment Committee
```

## Primary question

> Where does the institutional team disagree, and what evidence would resolve the disagreement?

## Outputs

- Explicit analyst positions with evidence, assumptions, confidence and open questions
- Agreement and disagreement matrices
- Evidence and assumption conflicts
- Moderator summary
- Consensus state and sufficiency
- Minority report with majority triggers
- Three-round **Challenge Tournament** with position revision
- **Debate Scorecard** measuring how well AGIB argued with itself

## Quality rules

≥3 supporting positions · ≥2 challenged assumptions · ≥2 evidence conflicts · ≥1 minority view · ≥1 unresolved question
