# Institutional Documents Intelligence (IDI)

## Principle

```
Document → Collector → Validator → Parser → Knowledge Object → Evidence Pack → Platform
```

Never `Document → Reasoning`.

No summarisation. No recommendations.

## Frozen systems

Phase 1–7, Knowledge Factory core, IKS soft layers, Ask, Scheduler, Research Office, LIDI — soft-wire only.

## Objects

AnnualReportObject, QuarterlyReportObject, PresentationObject, TranscriptObject,
GovernanceObject, RiskDisclosureObject, AccountingNoteObject, SegmentObject

## APIs

`/v1/documents/{dashboard,company/{ticker},report/{id},search,replay,health}`
