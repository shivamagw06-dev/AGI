# Conviction portfolios

Two India research portfolios: `in-conviction-long` (71 unique stocks, 97 category positions) and `in-conviction-short` (56 unique stocks, 87 category positions). There are 100 distinct stocks across both sides and 27 overlaps. Every source category membership is retained.

Source: user-supplied JPM_Asia_Quantamental_Up_2026-09-24_5462124.xlsm, India rows only. Cover date is 1 September, filename date 24 September; neither establishes the exact signal availability date. These are not current recommendations. Source sheets supply Composite, Value, Growth, Quality, Momentum and Low Vol extreme-decile scores. Full precision, original cell references and source tickers are retained. Blank factors are not zero scores.

AGI assigns exactly one-sixth to each category, equal stock weights within each. Weights are stored at full precision and combined by symbol for overall exposure. This is an AGI model allocation, not JPM-prescribed weights. Rebuild with `scripts/portfolios/build_conviction.py` using the original workbook, the symbol-mapping workbook and an Upstox NSE instrument-master gzip. All 100 symbols matched EQ instrument keys in the saved master, including VAML, TMPV and TMCV. This is instrument matching, not evidence of executable shorts.

Publication inserts the two JSON documents from `server/data/indiaConvictionPortfolios.json` into the existing portfolio catalog. No new table/service is required. IDs are added to the existing Monday 5 October launch scheduler and 4 pm daily collector. A full set of fresh quotes is required to establish each portfolio's launch; missing/stale/changed instruments block launch. No retrospective launch or fabricated history. Categories and direction are frozen in the baseline alongside holdings. The flat admin editor rejects Conviction edits because they would invalidate linked category weights. A future dated rebalance workflow is required.

Stored daily marks are the positive underlying weighted price index for both sides. The response transforms the short research view to `200 - underlying index`, i.e. cumulative P&L against 100 initial short notional. It is not daily-reset inverse exposure or a margin-account NAV, and may fall below zero. Excludes borrowing, commissions, taxes, dividends owed, financing and execution. No orders. The long price return also excludes fees/dividends/corporate-action adjustment.

Categories use the same frozen launch prices as their parent. A category point requires all category stocks for that date; a parent point requires all parent holdings. Missing stocks never trigger reweighting. Category dates are visible and can differ when data is incomplete. Total return equals the initial-allocation-weighted category returns on a common complete date. Stock columns separate underlying price return from directional strategy return.

Validation: 17 focused tests cover source cardinality, allocation reconciliation, category/total equality, missing-data suppression, short direction and uncapped loss, instrument-identity mismatch, launch timing and read-only catalog API. Production build passes. Local browser fixtures check six categories per side, category membership switching, mobile width and no page exceptions. Live data collection remains pending the launch session.
