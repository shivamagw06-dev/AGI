# AGIB v1.0 — Post-GA Success Metrics

After General Availability, measure product and operational outcomes — not architectural expansion.

## Product

| Metric | Intent |
|--------|--------|
| Daily / weekly active analysts | Adoption |
| Workspace engagement | Habitual research use |
| Publication generation success rate | Delivery reliability |
| Research output quality | Institutional usefulness |
| Customer retention / satisfaction | Product-market fit |

## Performance & Ops

| Metric | Intent |
|--------|--------|
| Median Ask AGI response time | Speed (PRP-01 targets) |
| Data freshness SLAs | Evidence currency |
| System availability | Operability |
| Production incident rate | Stability |
| Architecture conformance rate | Drift prevention (target 100%) |

## Explicitly de-emphasized

* PR count
* Engine count
* Module count

Those measured building the platform. GA success is whether analysts use it every day.
